    달의 고리 전용 설치 안내

    Android에서 오프라인으로 플레이

    1. 인터넷에 연결된 상태에서 이 페이지를 Chrome으로 여세요.
    2. 앱 설치 버튼을 누르거나 Chrome의 ⋮ → 홈 화면에 추가 → 설치를 선택하세요. Chrome 버전에 따라 메뉴 이름이 다를 수 있어요.
    3. 홈 화면의 달의 고리 아이콘으로 앱을 한 번 열고, 이 안내에서 오프라인 준비 완료를 확인하세요. 비행기 모드에서 아이콘으로 다시 열어 보면 확인할 수 있어요.

    Android에서 달의 고리 바로 열기

    iPhone·iPad Safari에서 공유 → 홈 화면에 추가를 선택하고, 표시되면 웹 앱으로 열기를 켜세요.

    설치한 앱을 인터넷이 연결된 상태에서 한 번 열고 오프라인 준비 완료가 표시되면 오프라인에서 시작할 수 있어요.

    iPhone·iPad용 홈 화면 바로가기 구성 프로파일 다운로드. 서명되지 않은 바로가기 프로파일이에요. 내려받은 뒤 설정에서 설치하면 바로가기가 추가돼요.

    테스트 서명 프로파일 열기. 자체 서명이라 기기에서 검증되지 않음으로 표시될 수 있어요.

    이승현 서명 프로파일 열기. 자체 서명이라 기기에서 검증되지 않음으로 표시될 수 있어요.

    iPad에서 HTML 파일로 플레이

    1. 게임 HTML 다운로드 후 파일 앱의 나의 iPad에 저장하세요.
    2. Open HTML file 단축어 열기에서 단축어 추가를 누르세요.
    3. 파일 앱에서 moon-offline.html을 길게 누르고 공유 → Open HTML file을 선택하세요.

    Open HTML file 단축어 파일 다운로드

    공유 메뉴에 없으면 단축어 앱에서 Open HTML file을 실행하고 게임 파일을 고르세요.

    게임 방법

    내 카드 한 장을 게임판의 빈 칸으로 끌어 놓으세요. 카드와 빈 칸을 차례로 눌러도 돼요. 카드 선택 중 빈 칸에 표시되는 숫자는 이번 수로 얻는 점수예요. 나와 반달이 한 장씩 번갈아 놓아요. 카드는 가로나 세로로 이어집니다.

    같은 위상 페어 · 1점
    같은 모습의 달 두 장을 이어요.
    보름달 페어 · 2점
    밝은 부분과 어두운 부분이 서로 반대인 두 달을 이어요.
    보름달 연속 보너스
    가로 또는 세로로 보름달 4장 +10점, 5장 +20점. 이후 한 장마다 +10점이 추가돼요. 새 카드가 포함된 연속 줄을 계산하며 기존 조합 점수에 더해져요.
    달의 순환 · 카드당 1점
    아래 위상 순서대로 3장 이상 이어요. 삭과 그믐달도 이어집니다.

    조합에 포함된 카드는 내 영역으로 바뀌어요. 판이 차면 내 영역 카드 한 장당 1점을 더하고, 총점이 높은 쪽이 이겨요.
