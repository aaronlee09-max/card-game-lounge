Android · 링크로 바로 시작

달의 고리 바로 열기

파일을 받지 않아도 위 링크를 Chrome에서 열면 바로 플레이할 수 있어요.

홈 화면에 앱 아이콘 추가

  1. 위 게임 링크를 Chrome에서 여세요.
  2. Chrome 메뉴의 홈 화면에 추가 또는 앱 설치를 선택하세요. 설치 버튼이 나타나면 그 버튼을 눌러도 돼요.
  3. 이름이 달의 고리인지 확인하고 추가하세요. 다음부터 홈 화면의 게임 아이콘으로 실행하세요.

인터넷 없이 플레이하기

  1. 인터넷이 연결된 상태에서 이 설치 안내를 열고 아래 오프라인 준비 완료 표시를 확인하세요.
  2. 게임을 한 번 실행한 뒤 홈 화면 아이콘으로 다시 열어 보세요.
  3. 비행기 모드를 켜고 혼자 플레이가 열리는지 확인하세요. QR·링크 초대와 온라인 매칭에는 인터넷이 필요해요.
설치 메뉴가 안 보이거나 오프라인에서 안 열려요

다른 앱 안의 브라우저 대신 Chrome에서 게임 링크를 직접 여세요. 설치 대신 바로가기 추가만 표시될 수도 있어요. 오프라인 준비에 실패하면 인터넷을 켜고 설치 안내를 다시 열어 주세요. 브라우저의 사이트 데이터를 지우면 다시 준비해야 해요.

이 프로파일에는 달의 고리 아이콘과 바로가기 한 개가 들어 있어요. 미서명 프로파일이라 설치 시 경고가 표시될 수 있어요.

iPad에서 HTML 열기

  1. HTML 파일을 파일 앱의 나의 iPad에 저장하세요.
  2. Open HTML file 단축어 추가
  3. moon-offline.html을 길게 누르고 공유 → Open HTML file을 선택하세요.

단축어 파일 다운로드

프로파일로 추가한 아이콘은 개별 삭제할 수 없어요. 제거하려면 설정 → 일반 → VPN 및 기기 관리에서 해당 프로파일을 삭제하세요. Safari·Chrome에서 직접 추가한 아이콘에는 적용되지 않아요.

오프라인 준비

인터넷이 연결된 상태에서 달의 고리 앱을 한 번 열어 주세요. 친구 초대 대전에는 인터넷 연결이 필요해요.
